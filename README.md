## Standards

- **Color coding:** Blue cells = hardcoded inputs · Green cells = cross-sheet links · Black = formulas
- **Single source of inputs** — every hardcoded number lives on the Assumptions tab; covers, sensitivity grids, scenarios, price targets and ratings are live formulas
- **PDFs tie to the models** — every figure in each note is read from its recalculated workbook
- **No circular references** — interest calculated on beginning-of-period balances
- **Audit trail** — all assumptions documented on dedicated Assumptions tab
- **IB-style formatting** — headers, borders, and number formats match sell-side deliverable standards
- **Branded deliverables** — every Excel sheet and PDF page carries a running portfolio header/footer
